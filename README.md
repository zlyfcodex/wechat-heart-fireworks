# 微信爱心烟花

这是可以直接发布到 GitHub Pages 的静态网站项目。

## 使用 GitHub Desktop 发布

1. 安装并登录 GitHub Desktop。
2. 选择 File -> Add local repository。
3. 选择这个文件夹：

   `C:\Users\Lenovo\Documents\Codex\2026-10-12\ban\outputs\github-pages-repo`

4. 如果 GitHub Desktop 提示还不是 Git 仓库，按提示创建仓库。
5. 仓库名建议填写：`wechat-heart-fireworks`。
6. 提交后点击 Publish repository，选择 Public。
7. 等待 GitHub Actions 自动部署。
8. 发布地址通常为：

   `https://你的用户名.github.io/wechat-heart-fireworks/`

如果自动部署失败，在仓库的 Settings -> Pages 中，把 Source 设置为 GitHub Actions，然后重新运行部署工作流。
